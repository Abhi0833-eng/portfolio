## 🌟 Key Features

- 🧠 **Interactive LangGraph Agentic AI Sandbox**: Live step-by-step simulator showcasing autonomous multi-agent state transitions (`Researcher` ➔ `Fact-Checker` ➔ `Report Writer` ➔ `Critique & Self-Revision`).
- 🌓 **Adaptive Dark / Light Theme Engine**: Powered by Tailwind CSS v4 custom variant class strategy with `localStorage` preference persistence.
- 📄 **Dual-Resume Selection Engine**: Recruiter modal with instant preview and PDF download options for:
  - 🤖 **AI / ML & Agentic AI Specialist Resume**
  - 💻 **Full-Stack Web Engineering Resume**
- 🎯 **Filterable Projects Showcase**: Categorized project cards with live metrics, architecture breakdowns, and direct live links (LangGraph Autonomous Research Agent, TriageIQ RAG Engine, Smart Panchayat, AI Resume Analyzer, Loan Default Predictor, StellarPay).
- 🏆 **IEEE Publication & Award-Winning Innovations**: Dedicated showcases for First-Author IEEE Xplore publication (*Intelligent Accident Detection using FPGA*) and **Smart MedTech IoT Health Gloves** (*1st Place Winner @ IIIT Delhi Esya'23*).
- ⚡ **Direct Action Triggers**: Integrated quick-connect buttons for WhatsApp chat, mailto compose, direct phone call dialer, and Google Maps location search.

## 💻 Local Setup & Quick Start

Follow these steps to run the portfolio on your local machine:

### 1. Clone Repository
```bash
git clone https://github.com/Abhi0833-eng/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
